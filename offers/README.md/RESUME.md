# Hyprland Empty-Workspace Dock — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a second Waybar bar that shows a glassy 12-icon app-dock exclusively on empty Hyprland workspaces, with usage tracking, pinning, and add/remove capabilities.

**Architecture:** A Bash daemon (`waybar-monitor.sh`) polls `hyprctl` every 2 s, shows/hides a dedicated Waybar instance when the active workspace has zero windows. A JSON database (`apps.json`) tracks launch counts and pin flags; `update-launchers.sh` regenerates Waybar's custom modules from it. Each icon is a `custom/` Waybar module whose `exec` calls `launch-app.sh` and whose `on-click-right` calls `context-menu.sh`.

**Status: DEPLOYED AND RUNNING** — systemd user service `empty-dock.service` is enabled on NixOS 25.11, verified working 2026-05-02. Bug-fix pass applied 2026-05-02: icon rendering fixed, 10 apps populated, max slots reduced to 10, position adjusted.

**Tech Stack:** Bash 5, jq, hyprctl (Hyprland IPC), socat, Waybar ≥0.9.24, rofi (app picker), bats-core (shell tests), NixOS / home-manager.

---

## Debugging Policy

- **LOG_FILE**: All daemon output goes to `~/.local/share/empty-dock/empty-dock.log`.
  Every script sources a shared `lib/log.sh` that writes `[LEVEL] timestamp message` lines.
- **DRY_RUN mode**: Set `EMPTY_DOCK_DRY_RUN=1` to prevent any `exec`/`waybar`/`pkill` side effects; scripts print actions instead.
- **Unit tests**: 8 tests in `tests/run_tests.sh` (plain Bash runner; `bats` not available on this system). Run with `bash tests/run_tests.sh`. Results: 8/8 pass.
- **Mock hyprctl**: `tests/mocks/hyprctl` dispatches by command using `$HYPRCTL_FIXTURE_DIR` (per-command fixture files) or falls back to legacy `$HYPRCTL_FIXTURE`.
- **Incremental delivery order**: detection → bar config → static icons → usage tracking → pinning → NixOS module.

```bash
#!/usr/bin/env bash
# empty-dock/waybar-monitor.sh
# Guard so tests can source without running main loop
[[ "${1:-}" == "--source-only" ]] && return 0

set -euo pipefail
SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
source "$SCRIPT_DIR/lib/log.sh"

WAYBAR_CMD="${WAYBAR_CMD:-waybar}"
WAYBAR_CONFIG="$SCRIPT_DIR/config.jsonc"
WAYBAR_STYLE="$SCRIPT_DIR/style.css"
DOCK_PID_FILE="/tmp/empty-dock-waybar.pid"
POLL_INTERVAL="${EMPTY_DOCK_POLL:-2}"

# Returns 0 if workspace $1 has no windows, 1 otherwise.
workspace_is_empty() {
  local ws_id="$1"
  local windows
  windows=$(hyprctl workspaces -j \
    | jq --argjson id "$ws_id" '.[] | select(.id == $id) | .windows')
  [[ "${windows:-1}" -eq 0 ]]
}

# Returns the currently focused workspace id.
active_workspace_id() {
  hyprctl activeworkspace -j | jq '.id'
}
```

```bash
dock_is_running() {
  [[ -f "$DOCK_PID_FILE" ]] && kill -0 "$(cat "$DOCK_PID_FILE")" 2>/dev/null
}

dock_show() {
  dock_is_running && return 0
  if [[ "${EMPTY_DOCK_DRY_RUN:-0}" == "1" ]]; then
    log_info "DRY_RUN: start waybar -c $WAYBAR_CONFIG -s $WAYBAR_STYLE"
    return 0
  fi
  log_info "Showing dock"
  "$WAYBAR_CMD" -c "$WAYBAR_CONFIG" -s "$WAYBAR_STYLE" &
  echo $! > "$DOCK_PID_FILE"
}

dock_hide() {
  if [[ "${EMPTY_DOCK_DRY_RUN:-0}" == "1" ]]; then
    local pid
    pid=$(cat "$DOCK_PID_FILE" 2>/dev/null || echo "none")
    log_info "DRY_RUN: kill $pid"
    return 0
  fi
  if dock_is_running; then
    log_info "Hiding dock"
    kill "$(cat "$DOCK_PID_FILE")" && rm -f "$DOCK_PID_FILE"
  fi
}

main() {
  log_info "empty-dock monitor started (poll=${POLL_INTERVAL}s)"
  local last_state=""
  while true; do
    local ws_id
    ws_id=$(active_workspace_id)
    if workspace_is_empty "$ws_id"; then
      [[ "$last_state" != "empty" ]] && dock_show
      last_state="empty"
    else
      [[ "$last_state" != "busy" ]] && dock_hide
      last_state="busy"
    fi
    sleep "$POLL_INTERVAL"
  done
}

main "$@"
```

- [x]**Step 6.4 — Implement `update-launchers.sh`**

```bash
#!/usr/bin/env bash
# empty-dock/update-launchers.sh
# Regenerates config.jsonc from apps.json, placing top-12 apps into slots.
set -euo pipefail
SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
source "$SCRIPT_DIR/lib/log.sh"

APPS_FILE="${EMPTY_DOCK_APPS:-$SCRIPT_DIR/apps.json}"
CONFIG_OUT="${EMPTY_DOCK_CONFIG_OUT:-$SCRIPT_DIR/config.jsonc}"
LAUNCH_SCRIPT="$SCRIPT_DIR/launch-app.sh"
CTX_SCRIPT="$SCRIPT_DIR/context-menu.sh"

# Build sorted top-12 list: pinned first (stable), then by launch_count desc
top12=$(jq -r '
  .apps
  | sort_by([if .pinned then 0 else 1 end, -(.launch_count)])
  | .[0:12]
' "$APPS_FILE")

# Generate module entries for slots 0-11
module_entries=""
for i in $(seq 0 11); do
  entry=$(echo "$top12" | jq -r --argjson i "$i" '
    if .[$i] then
      .[$i] | {
        exec:           ("'"$LAUNCH_SCRIPT"' \(.exec) \(.name | @sh) --print-icon \(.icon)"),
        "return-type":  "json",
        interval:       "once",
        "on-click":     ("'"$LAUNCH_SCRIPT"' \(.exec) \(.name | @sh)"),
        "on-click-right": ("'"$CTX_SCRIPT"' \(.id)")
      }
    else
      {exec: "echo '"'"'{\"text\":\"·\",\"tooltip\":\"empty\"}'"'"'", "return-type": "json", interval: "once"}
    end
  ')
  module_entries=$(printf '%s\n  "custom/app%d": %s,' "$module_entries" "$i" "$entry")
done

# Assemble final config
python3 - <<PYEOF
import json, sys

raw = open("$CONFIG_OUT").read() if __import__('os').path.exists("$CONFIG_OUT") else "{}"
try:
    cfg = json.loads(raw)
except Exception:
    cfg = {}

# Preserve structural keys, inject module definitions
cfg["layer"]       = "top"
cfg["position"]    = "top"
cfg["height"]      = 88
cfg["margin-top"]  = 38
cfg["margin-left"] = 113
cfg["exclusive"]   = False
cfg["passthrough"] = False
cfg["gtk-layer-shell"] = True
cfg["reload_style_on_change"] = True
cfg["modules-left"]   = ["custom/app{}".format(i) for i in range(12)] + ["custom/add"]
cfg["modules-center"] = []
cfg["modules-right"]  = []

import subprocess, json as _json
top12_raw = subprocess.check_output(
    ["jq", "-c",
     ".apps | sort_by([if .pinned then 0 else 1 end, -(.launch_count)]) | .[0:12]",
     "$APPS_FILE"]).decode()
top12 = _json.loads(top12_raw)

for i in range(12):
    key = "custom/app{}".format(i)
    if i < len(top12):
        app = top12[i]
        cfg[key] = {
            "exec": "{} {} {} --print-icon {}".format(
                "$LAUNCH_SCRIPT", app["exec"], app["name"], app["icon"]),
            "return-type": "json",
            "interval": "once",
            "on-click": "{} {} {}".format("$LAUNCH_SCRIPT", app["exec"], app["name"]),
            "on-click-right": "{} {}".format("$CTX_SCRIPT", app["id"])
        }
    else:
        cfg[key] = {
            "exec": "echo '{\"text\":\"·\",\"tooltip\":\"empty slot\"}'",
            "return-type": "json",
            "interval": "once"
        }

cfg["custom/add"] = {
    "exec": "echo '{\"text\":\" +\"}'",
    "return-type": "json",
    "interval": "once",
    "on-click": "$SCRIPT_DIR/add-app.sh"
}

print(_json.dumps(cfg, indent=2))
PYEOF | tee "$CONFIG_OUT" > /dev/null

log_info "Config written to $CONFIG_OUT"
```

```bash
# empty-dock/launch-app.sh
# Usage: launch-app.sh <exec> <name> [--print-icon <icon>]
set -euo pipefail

source "$SCRIPT_DIR/lib/log.sh"

APP_NAME="$2"

ICON_NAME=""

if [[ "${3:-}" == "--print-icon" ]]; then
  PRINT_ICON=1
  ICON_NAME="${4:-}"
fi

# Increment launch_count for the matching app
tmp=$(mktemp)
jq --arg exec "$APP_EXEC" '
  .apps |= map(if .exec == $exec then .launch_count += 1 else . end)
' "$APPS_FILE" > "$tmp" && mv "$tmp" "$APPS_FILE"

# If called for icon display (Waybar exec), print JSON and exit
if [[ "$PRINT_ICON" -eq 1 ]]; then
  # Resolve XDG icon path (best-effort: return the icon name; Waybar renders it via GTK)
  echo "{\"text\":\"$ICON_NAME\",\"tooltip\":\"$APP_NAME\"}"
  exit 0
fi

# Actually launch the app
log_info "Launching $APP_NAME ($APP_EXEC)"
if [[ "${EMPTY_DOCK_DRY_RUN:-0}" == "1" ]]; then
  log_info "DRY_RUN: exec $APP_EXEC"
  exit 0
fi

# Run detached so Waybar's on-click doesn't wait
nohup "$APP_EXEC" &>/dev/null &
disown
```

```bash
#!/usr/bin/env bash
# empty-dock/context-menu.sh
# Usage: context-menu.sh <app_id>
set -euo pipefail
SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
source "$SCRIPT_DIR/lib/log.sh"

APP_ID="$1"
APPS_FILE="${EMPTY_DOCK_APPS:-$SCRIPT_DIR/apps.json}"

APP_NAME=$(jq -r --argjson id "$APP_ID" '.apps[] | select(.id == $id) | .name' "$APPS_FILE")
IS_PINNED=$(jq -r --argjson id "$APP_ID" '.apps[] | select(.id == $id) | .pinned' "$APPS_FILE")

PIN_LABEL="Pin"
[[ "$IS_PINNED" == "true" ]] && PIN_LABEL="Unpin"

# Present menu via rofi (falls back to wofi)
choice=$(printf '%s\nRemove' "$PIN_LABEL" \
  | rofi -dmenu -p "$APP_NAME" 2>/dev/null \
  || printf '%s\nRemove' "$PIN_LABEL" \
  | wofi --dmenu --prompt "$APP_NAME")

tmp=$(mktemp)
case "$choice" in
  Pin)
    jq --argjson id "$APP_ID" '
      .apps |= map(if .id == $id then .pinned = true else . end)
    ' "$APPS_FILE" > "$tmp" && mv "$tmp" "$APPS_FILE"
    log_info "Pinned app id=$APP_ID"
    ;;
  Unpin)
    jq --argjson id "$APP_ID" '
      .apps |= map(if .id == $id then .pinned = false else . end)
    ' "$APPS_FILE" > "$tmp" && mv "$tmp" "$APPS_FILE"
    log_info "Unpinned app id=$APP_ID"
    ;;
  Remove)
    jq --argjson id "$APP_ID" '
      .apps |= map(select(.id != $id))
    ' "$APPS_FILE" > "$tmp" && mv "$tmp" "$APPS_FILE"
    log_info "Removed app id=$APP_ID"
    ;;
  *)
    rm -f "$tmp"
    exit 0
    ;;
esac

# Rebuild config after change
bash "$SCRIPT_DIR/update-launchers.sh"
# Signal Waybar to reload
pkill -USR2 waybar 2>/dev/null || true
```

```bash
#!/usr/bin/env bash
# empty-dock/add-app.sh
# Opens rofi/wofi to pick a .desktop entry, adds it to apps.json
set -euo pipefail
SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
source "$SCRIPT_DIR/lib/log.sh"

APPS_FILE="${EMPTY_DOCK_APPS:-$SCRIPT_DIR/apps.json}"

# Build list of installed apps from .desktop files
desktop_list=$(grep -rh '^Name=' /usr/share/applications/ ~/.local/share/applications/ 2>/dev/null \
  | sed 's/^Name=//' | sort -u)

chosen=$(echo "$desktop_list" \
  | rofi -dmenu -p "Add app" 2>/dev/null \
  || echo "$desktop_list" | wofi --dmenu --prompt "Add app")

[[ -z "$chosen" ]] && exit 0

# Find the desktop file for the chosen name
desktop_file=$(grep -rl "^Name=$chosen$" /usr/share/applications/ ~/.local/share/applications/ 2>/dev/null | head -1)
[[ -z "$desktop_file" ]] && log_error "Desktop file not found for: $chosen" && exit 1

exec_line=$(grep '^Exec=' "$desktop_file" | head -1 | sed 's/^Exec=//' | sed 's/ %.*//')
icon_line=$(grep '^Icon=' "$desktop_file" | head -1 | sed 's/^Icon=//')

# Generate next id
next_id=$(jq '.apps | map(.id) | max + 1 // 0' "$APPS_FILE")

tmp=$(mktemp)
jq --argjson id "$next_id" \
   --arg name "$chosen" \
   --arg exec "$exec_line" \
   --arg icon "$icon_line" '
  .apps += [{
    "id": $id,
    "name": $name,
    "exec": $exec,
    "icon": $icon,
    "launch_count": 0,
    "pinned": false
  }]
' "$APPS_FILE" > "$tmp" && mv "$tmp" "$APPS_FILE"

log_info "Added app: $chosen ($exec_line)"
bash "$SCRIPT_DIR/update-launchers.sh"
pkill -USR2 waybar 2>/dev/null || true
```

```nix
  cfg = config.services.emptyDock;

      type = types.int;
      default = 2;
      description = "Seconds between workspace checks.";
    };

      type = types.str;
      default = "$HOME/.local/share/empty-dock/empty-dock.log";
      description = "Path for the daemon log file.";
    };

    home.packages = with pkgs; [
      waybar
      jq
      rofi-wayland
      hyprland  # provides hyprctl
      socat
      python3
    ];

    # Install scripts
    home.file."${dockDir}" = {
      source = ./.;
      recursive = true;
    };

    # Systemd user service
    systemd.user.services.empty-dock = {
      Unit = {
        Description = "Hyprland empty-workspace dock monitor";
        After = [ "graphical-session.target" ];
        PartOf = [ "graphical-session.target" ];
      };
      Service = {
        ExecStart = "${dockDir}/waybar-monitor.sh";
        Restart = "on-failure";
        RestartSec = 3;
        Environment = [
          "EMPTY_DOCK_POLL=${toString cfg.pollInterval}"
          "EMPTY_DOCK_LOG=${cfg.logFile}"
        ];
      };
      Install.WantedBy = [ "graphical-session.target" ];
    };
  };
}
```

1. **`[class^="..."]` attribute selectors** — not supported in GTK3 CSS
   - Fix: replace with explicit `#custom-app0, ..., #custom-app11` ID selectors

   - Fix: removed; used `opacity` for active state instead
3. **`transition` with transform** — simplified to `transition: background 0.15s ease`
